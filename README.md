# ProtectHer

A web-based platform for gender-based violence reporting in Nigeria.

Built with React.js and Supabase.

## Features
- Anonymous GBV report submission
- Case ID tracking system
- Automated NGO assignment
- NGO and Admin dashboards
- Quick Exit safety button

## Tech Stack
- React.js + Vite
- Supabase (Database + Auth)
- EmailJS (Notifications)
- Vercel (Deployment)
